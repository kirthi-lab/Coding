# Java Tutorial: Beginner to Advanced

A practical, example-driven guide to learning Java from the ground up. Every concept is paired with runnable code and a real-world use case so you learn not just the syntax, but *when and why* to use it.

## Who this is for

- Complete beginners who have never written a line of Java
- Developers coming from another language who want a fast, practical ramp-up
- Intermediate Java developers who want to solidify OOP, collections, and modern features

## How to use this tutorial

Work through the sections in order. Each file builds on the previous one. Type the examples out yourself instead of copy-pasting, and run them. Break them on purpose to see what the compiler and runtime tell you.

## Prerequisites

- A computer running Windows, macOS, or Linux
- Willingness to run code and read error messages carefully

## Quick reference: the toolchain

| Tool | Purpose |
|------|---------|
| **JDK** (Java Development Kit) | Compiles and runs Java. Includes `javac` (compiler) and `java` (runtime). |
| **JRE** (Java Runtime Environment) | Runs compiled Java. Bundled inside the JDK. |
| **JVM** (Java Virtual Machine) | Executes Java bytecode. Enables "write once, run anywhere". |
| **IDE** (IntelliJ IDEA, Eclipse, VS Code) | Editor with autocomplete, debugging, and build tooling. |
